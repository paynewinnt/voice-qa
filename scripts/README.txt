================================================================================
                        Text-to-Speech 文本转语音工具
                           Windows GUI 版使用文档
================================================================================

一、部署说明
--------------------------------------------------------------------------------
    将压缩包解压到任意目录即可使用，无需安装 Python 或其他开发环境。

    目录结构:
    ├── 语音播测工具.exe   # GUI 主程序
    ├── config.json                  # 配置文件
    ├── text.txt                     # 文本文件 (每行一条)
    ├── ttsengine/                   # 离线TTS引擎 (已包含)
    ├── models/                      # 离线语音模型 (已包含)
    ├── ffmpeg/                      # 音频处理工具 (已包含)
    ├── adb/                         # ADB工具 (已包含)
    └── output/                      # 输出目录 (wav、manifest、playtest-* 测试结果)

    【注意】使用 Piper 离线语音时，首次运行需安装 VC++ 运行库:
    下载地址: https://aka.ms/vs/17/release/vc_redist.x64.exe


二、快速开始
--------------------------------------------------------------------------------

    1. 双击运行 "语音播测工具.exe"

    2. 在"生成语音"标签页:
       - 点击"打开文件编辑"修改 text.txt
       - 点击"刷新列表"查看文本
       - 点击"批量生成语音"开始生成

    3. 在"设备管理"标签页:
       - 输入设备 IP 并点击"连接"
       - 或点击"刷新列表"检查 USB / 已连接设备
       - 可选择目标设备后手动录屏，停止后保存到 output/recordings
       - 安装 APK 默认保留数据覆盖，不会自动卸载、清数据或降级
       - 网络设备离线时只重连当前目标；使用 adb install --streaming --no-incremental -r 直接安装，设备端不另存 APK，也不回退到 push
       - 安装过程显示阶段和已耗时；本机英文临时副本用后删除，并尝试清理旧版固定缓存；超时或中断请先查询设备应用版本
       - 同版本仍失败时请查看具体原因，签名冲突、versionCode 降级不能靠重复安装解决

    4. 在"性能测试"标签页:
       - 选择应用包名后自动加载可能的 Component
       - 可执行单次启动计时或批量启动测试
       - 单次和批量记录均可勾选生成聚合报告，不同设备和启动条件分别统计
       - 下方可对已打开并保持前台的 APK 执行多设备综合性能测试

    5. 在"播放模式"标签页:
       - 多设备场景先选择"目标设备"
       - 点击"开始播放"运行测试

    6. 在"配置设置"标签页:
       - 选择语音引擎和声音
       - 可视化编辑语音模板
       - 点击"保存配置"应用更改


三、语音引擎说明
--------------------------------------------------------------------------------

    本工具支持两种语音引擎:

    1. Edge TTS (在线，推荐)
       - 需要联网
       - 音质更好，支持多种声音
       - 可选声音:
         * 云健 (播音男声) [默认]
         * 云希 (标准男声)
         * 云扬 (新闻男声)
         * 云夏 (少年男声)
         * 晓晓 (标准女声)
         * 晓伊 (甜美女声)
         * 晓北 (东北女声)
         * 晓妮 (陕西女声)

    2. Piper (离线)
       - 无需联网
       - 需要安装 VC++ 运行库
       - 声音: 中文女声


四、语音模板编辑
--------------------------------------------------------------------------------

    在"配置设置"标签页可以可视化编辑语音模板:

    - 点击 "+ 添加语音" 添加语音片段
    - 点击 "+ 添加静音" 添加静音片段
    - 使用 ↑↓ 按钮调整顺序
    - 点击"删除"移除片段
    - $MAIN 代表主文本内容，不可删除

    默认模板结构:
    [静音1秒] → [小翼管家] → [静音2秒] → [文本内容] → [静音18秒]
             → [小翼管家] → [静音2秒] → [返回首页] → [静音5秒]


五、播放模式说明
--------------------------------------------------------------------------------

    播放模式需要连接 Android 设备，用于:
    1. 播放语音文件
    2. 记录设备 logcat 日志
    3. 在语音结束前自动截图
    4. 可选录制设备屏幕视频
    5. 按 wav 对应原文做日志断言验证

    连接方式:
    - USB: 开启设备的 USB 调试，连接电脑后点击"刷新列表"
    - 无线: 输入设备 IP 地址，点击"连接"

    生成结果保存在 output/ 根目录:
    - *.wav           语音文件
    - manifest.json   wav 到原文的映射关系

    每次播放会生成独立会话目录:
    - playtest-*/test_report.txt  测试报告
    - playtest-*/*.log            logcat 日志
    - playtest-*/*.png            截图
    - playtest-*/*.mp4            录屏（启用视频录制时）


六、性能测试说明
--------------------------------------------------------------------------------

    性能测试包含启动性能和应用综合性能。

    启动性能用于查看 Android 应用冷启动耗时。

    1. 先在"设备管理"连接并选择设备
    2. 在"性能测试"选择应用包名
    3. 在"完整 Component 名称"下拉框选择候选 Activity
       - 如果未解析到候选项，可手动填写，例如 com.example/.MainActivity
    4. 可按需执行 force-stop、pm clear、返回首页、停止第三方应用
    5. 可执行单次测试，也可设置次数、间隔、采集时长后批量运行
    6. 勾选需要统计的测试记录，选择 TotalTime、手动(ms) 或两者，再计算平均值或生成聚合报告

    手动(ms)从后端实际发出启动命令开始，直到用户停止请求到达后端，不包含启动前准备时间。
    只有成功启动并主动停止的记录计入手动统计；自动超时、批量采集和失败记录不计入。
    不同设备、Component、Intent、force-stop / pm clear 条件会分别统计，不计算跨组平均值。
    Deep Link 的 &、空格、引号等由工具统一转义，填写 Data URI 时无需自行添加转义符。

    输出位置:
    - output/perf/launch-*              单次启动测试结果
    - output/perf/batch-*/run-*/report.txt  单轮报告
    - output/perf/batch-*/summary.json      批量汇总数据
    - output/perf/batch-*/aggregate_report.txt 聚合测试报告

    Perfetto 为可选项。未勾选"启用 Perfetto"时，工具仍会使用 am start -W 和 logcat 完成基础启动计时。

    应用综合性能测试:
    1. 先在每台设备上打开应用，并保持相同的前台可操作页面
    2. 填写包名，选择设备、轮数和场景；场景格式为 名称,X,Y
    3. 坐标为 -1,-1 时只采样当前页面，不发送点击
    4. 运行期间不会执行 force-stop、pm clear、am start 或 monkey
    5. 测试会采集 CPU、PSS、线程、帧、稳定性、AudioFocus、网络和前后证据
    6. 运行中可停止并保存当前结果；目标离开前台或 PID 变化时自动停止后续点击
    7. 场景未完成、CPU/PSS 样本不足、零渲染帧或缺少帧 P90 时不判定通过
    8. 测试、验证入口、应用控制和 APK 安装按设备互斥；自定义 ADB 或外部工具仍需避免干扰测试

    综合性能输出位置:
    - output/performance/performance-*/performance_report.md  综合 Markdown 报告
    - output/performance/performance-*/combined-results.json  全设备结构化汇总
    - output/performance/performance-*/device-*/samples.csv    逐场景采样数据
    - output/performance/performance-*/device-*/*              原始日志、帧、内存、截图和 UI 证据


七、软件更新说明
--------------------------------------------------------------------------------

    "软件更新"标签页默认从公网云服务器检查新版本。

    默认地址:
    https://124.223.218.142/voice-qa/latest.json

    下载时会显示实时进度。校验完成后会启动不依赖 PowerShell 的原生更新器，
    保留 output、config.json、text.txt 和其他用户文件，自动覆盖程序文件并
    重启。文件短暂占用时会自动重试，安装失败时会回滚，详细记录保存在
    output/update-install.log。若程序目录不可写，请先将整个目录移动到普通
    用户可写位置。

    更新时逐文件合并 models、adb 等目录，保留其中额外添加的文件；遇到文件/目录
    类型冲突或目标符号链接时会中止并回滚，不直接删除用户路径。

    语音生成每完成一条即更新 manifest.json。点击停止会取消当前 Edge 请求或 Piper
    进程，已完成的语音及映射保留；运行中修改配置只影响后续生成任务。

    更新包没有固定的总下载时限，网络较慢时会继续等待。只有连续 5 分钟
    没有收到任何数据时才会中止；此时请检查公网连接后重试。


八、常见问题
--------------------------------------------------------------------------------

    Q: Edge TTS 连接失败
    A: 检查网络连接是否正常，确保能访问外网

    Q: piper 执行失败 (exit status 0xc0000409)
    A: 缺少 Visual C++ 运行库。请下载安装:
       https://aka.ms/vs/17/release/vc_redist.x64.exe

    Q: ADB 连接失败
    A: 确保设备已开启 USB 调试，或检查 IP 地址是否正确

    Q: 生成的语音有问题
    A: 检查 text.txt 编码是否为 UTF-8

    Q: 界面显示异常
    A: 确保系统已安装 WebView2 运行时 (Windows 10/11 通常已内置)
