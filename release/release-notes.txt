1. APK 安装改为 adb install --streaming --no-incremental -r，直接将安装包流传给 Android Package Manager，不再先 push 到设备暂存，也不会在失败后自动回退到暂存安装；设备或 ADB 不支持时明确提示。
2. 保留数据覆盖安装，不自动卸载旧应用、执行 pm clear 或强制降级。工具不再在设备端额外创建 APK 缓存；Android 安装器自身管理的安装会话、应用文件及存储空间需求仍然存在。
3. 保留 Windows 中文路径和带空格文件名兼容：仅在本机准备英文文件名临时副本，原始 APK 不变；正常返回、失败及取消后均尝试删除本机副本，清理失败明确告警。
4. 开始安装前尝试清理旧版工具遗留的固定缓存 /data/local/tmp/voice-qa-apk-cache.apk，最多等待 10 秒，仅删除该文件，不操作其他 APK 或应用数据；清理失败会保留警告，不把已成功安装误报为失败。
5. 安装界面改为显示当前阶段和已耗时，每 5 秒刷新。ADB 流式安装不提供可靠的字节进度，因此取消暂存模式的百分比、速度和预计剩余时间，不虚构进度，也不因命令长时间没有输出就误判传输停滞。
6. 流式传输与安装合计最多 30 分钟，完整任务最多 40 分钟；保留安装前在线检查和每步 15 秒时限，网络设备离线时只重连当前目标，不重启全局 ADB 服务。
7. 流式安装超时、取消或连接中断后不自动重试，明确提示设备端结果尚不确定，需要恢复连接并查询应用版本；取消后等待本地 ADB 进程结束再清理副本，避免进程仍占用文件。
8. 只有安装命令正常退出且收到独立的 Success 行才计为成功，保留 Package Manager 原始错误与签名不兼容、versionCode 降级、空间不足、ABI 不匹配等中文诊断；同时处理成功确认与取消发生在同一时刻的边界。
9. 补充强制流式模式、禁止 push 回退、旧缓存清理告警、中文路径、取消与超时、原始错误保留、成功判定及耗时显示回归测试，同步更新 README 和包内使用说明。局域网发现、多选连接和设备管理大日志布局继续保留；流式安装不保证突破网络本身的速度限制。
