1. 修复 APK 安装依赖默认流式传输、失败后只能看到简短错误的问题：改为先上传 APK，再执行 pm install -r 保留数据覆盖；正常的同版本兼容 APK 无需先卸载，工具不会自动卸载、清除应用数据或强制降级。
2. 新增设备在线预检；网络 ADB 设备离线时只断开并重新连接当前目标，等待其恢复在线，不执行全局 kill-server、不影响其他设备连接。未授权或 USB 设备不可用时明确提示检查授权与连接。
3. 安装前生成独立临时 APK 副本，传输时使用英文文件名及工作目录，设备端也使用独立英文临时路径，规避中文目录、中文文件名和空格参与远端安装命令的问题；原始 APK 保持不变。
4. APK 传输遇到明确的连接中断时，检查设备状态后最多重试一次；设备恢复失败或再次传输失败时立即报告，不无限循环重试。
5. 连接检查与恢复命令设置单步 15 秒超时，单次传输最多 5 分钟，Package Manager 安装最多 3 分钟，并设置整体安装时限；避免安装命令无反馈地长时间挂起。
6. 安装阶段超时或连接中断时明确提示设备端结果不确定，不盲目重复安装；需恢复连接并查询应用版本后再决定是否重试。成功与失败结束时都会尝试清理本次临时文件，清理失败不会把已成功安装误报为失败。
7. 保留 Package Manager 原始错误并补充中文诊断：区分签名不一致、versionCode 降级、存储空间不足、CPU 架构不兼容、Android 版本过低、APK 解析失败及设备策略限制。仅收到明确 Success 标记才报告安装成功。
8. GUI 新增安装阶段反馈，显示连接检查、重连、文件准备、传输和覆盖安装；安装期间锁定重复点击、文件选择与移除，设备刷新不会提前解锁安装按钮，本轮设备和 APK 列表保持固定。
9. 补充保留数据覆盖、离线恢复、单次重试、原始错误保留、取消清理、进程超时和前端批量安装状态回归测试，并同步更新 README 与 Windows 包内说明。
